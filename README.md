# desarrollo_web_Cristóbal_León

- Las reglas de JS se repiten en validations.py. Si hay errores, el formulario se vuelve a mostrar con la lista de campos inválidos.

- Se revisa el tipo real con filetype con un máximo de 5 archivos por avistamiento y 50 MB por envío.

- Como voluntario en la base de datos no tiene columna rut, el RUT solo se valida.

- Si el nombre del ave no existe en la tabla ave, se crea.

- Las filas se leen de la base de datos y listado.js las ordena (5 por página).

- Use los conocimientos de las clases auxiliares además de la ayuda de la IA para cosas que no entendiera e implementaciones usando conocimientos que no tenía previamente (Barreras con el lenguaje y funciones pre-hechas)
